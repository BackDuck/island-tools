Mac Island — установка

1. Распакуй архив (не запускай .app прямо из Telegram/почты).
2. Перетащи «Mac Island.app» в Программы (/Applications).
3. Первый запуск: ПКМ → «Открыть» → «Открыть».
   macOS ругается, потому что сборка без Apple Developer ID — это нормально.
4. Если не открывается:
   xattr -cr "/Applications/Mac Island.app"
   потом снова ПКМ → Открыть.

Использование
- Наведи на вырез сверху (Dynamic Island) — откроется панель.
- Если hover не ловится из других приложений:
  Настройки → Конфиденциальность → Мониторинг ввода → разреши Mac Island.

Требования: macOS 14+, Apple Silicon (M1/M2/M3/M4). Intel — эта сборка не подойдёт.
Версия: 1.0.1
