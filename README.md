# Mac Island

Небольшое нативное приложение для macOS в стиле Dynamic Island.

**Mac Island** появляется в верхней части экрана и объединяет несколько полезных функций в одном компактном интерфейсе: **управление музыкой, историю буфера обмена, изображения и заметки**.

Наведи курсор на верхнюю часть экрана — панель раскроется.

## Возможности

### 🎵 Музыка

Управляй воспроизведением, не переключаясь в музыкальное приложение.

* название трека и исполнитель;
* воспроизведение и пауза;
* предыдущий и следующий трек;
* прогресс воспроизведения;
* интеграция с системным Now Playing в macOS.

Для работы с медиаплеерами используется `MediaRemote.framework` — внутренний фреймворк Apple. Поэтому совместимость с будущими версиями macOS может меняться.

### 📋 Буфер обмена

Mac Island сохраняет историю скопированных данных.

История разделена на два раздела:

* **Текст** — ранее скопированный текст;
* **Изображения** — скопированные изображения.

Нажми на элемент, чтобы снова поместить его в буфер обмена.

Данные хранятся локально на компьютере:

```text
~/Library/Application Support/MacIsland/
```

### 📝 Заметки

В приложении есть простой раздел для заметок.

Он подходит для небольших фрагментов текста, которые хочется держать под рукой, не открывая отдельное приложение.

Заметки сохраняются локально на Mac.

### 🎨 Оформление

Mac Island поддерживает несколько вариантов оформления:

* серый;
* чёрный;
* белый;
* красный;
* зелёный;
* оранжевый;
* синий.

Также можно выбрать раздел, который будет открываться первым:

* Музыка;
* Текстовый буфер обмена;
* Изображения;
* Заметки;
* последний открытый раздел.

## Как это работает

Mac Island — нативное приложение для macOS, написанное на **Swift** с использованием **SwiftUI и AppKit**.

Основная панель представляет собой `NSPanel`, расположенную в верхней части экрана. Приложение отслеживает положение курсора и открывает интерфейс, когда курсор оказывается в соответствующей области.

Проект разделён на несколько компонентов:

```text
MacIsland/
└── Sources/
    ├── App/          Жизненный цикл приложения и общее состояние
    ├── Clipboard/    Буфер обмена и история
    ├── Media/        Управление воспроизведением
    ├── Notes/        Заметки
    ├── Panel/        Панель и отслеживание курсора
    └── UI/           Интерфейс SwiftUI
```

## Требования

* macOS 14 или новее;
* Xcode 15+, если собираете через Xcode;
* Apple Command Line Tools, если Xcode целиком не установлен.

Приложение можно собрать как на **Apple Silicon**, так и на **Intel Mac**:

* Apple Silicon — `arm64`;
* Intel — `x86_64`.

Скрипт сборки автоматически выбирает архитектуру текущего компьютера.

## Сборка

### Через скрипт

Если установлены Apple Command Line Tools, выполните:

```bash
chmod +x Scripts/build.sh
./Scripts/build.sh
```

После сборки приложение появится здесь:

```text
.build/app/Mac Island.app
```

Запустить его можно командой:

```bash
open ".build/app/Mac Island.app"
```

### Через Xcode

Для генерации Xcode-проекта используется [XcodeGen](https://github.com/yonaskolb/XcodeGen).

Установить его можно через Homebrew:

```bash
brew install xcodegen
```

Затем:

```bash
chmod +x Scripts/generate-project.sh
./Scripts/generate-project.sh
```

После этого открой:

```text
MacIsland.xcodeproj
```

Собрать проект из терминала:

```bash
xcodebuild \
  -project MacIsland.xcodeproj \
  -scheme "Mac Island" \
  -configuration Release \
  build
```

## Установка

Mac Island — приложение для строки меню, поэтому после запуска его значок находится в **menu bar**, а не в Dock.

При первом запуске macOS может показать предупреждение, поскольку приложение распространяется за пределами Mac App Store и в текущем процессе сборки не подписывается Apple Developer ID.

После запуска наведи курсор на верхнюю часть экрана, чтобы открыть Mac Island.

### Input Monitoring

Для отслеживания положения курсора macOS может потребовать разрешение **Input Monitoring**.

Если панель не реагирует на наведение курсора, открой:

**Системные настройки → Конфиденциальность и безопасность → Мониторинг ввода**

и разреши доступ для Mac Island.

После изменения разрешения перезапусти приложение.

## Где хранятся данные

Mac Island сохраняет данные локально на компьютере.

В частности, история буфера обмена и заметки находятся в:

```text
~/Library/Application Support/MacIsland/
```

Никакой облачной синхронизации для этих данных не требуется.

## Ограничения

### MediaRemote

Управление музыкой использует приватный фреймворк Apple — `MediaRemote.framework`.

Это не публичный API macOS, поэтому Apple может изменить его поведение в будущих версиях системы.

Из-за этого музыкальная часть приложения может потребовать обновлений после выхода новой версии macOS.

Остальные функции приложения от MediaRemote не зависят.

### Буфер обмена

Для создания истории Mac Island должен отслеживать системный буфер обмена.

Если эта функция вам не нужна, её можно не использовать — приложение продолжит работать с остальными разделами.

## Статус проекта

Mac Island — небольшой экспериментальный проект и персональный инструмент для macOS.

Идея простая: сделать компактную панель, которая не мешает работе и появляется только тогда, когда действительно нужна.

Если после обновления macOS что-то перестало работать, особенно управление музыкой или открытие панели при наведении, создай issue и укажи:

* версию macOS;
* модель Mac;
* процессор — Apple Silicon или Intel;
* что именно перестало работать;
* скриншот или логи, если они есть.
